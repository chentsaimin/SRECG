# SRECG 1.1

**SRECG** is an ECG signal super-resolution framework for improving low-resolution ECG signals used in cardiac arrhythmia classification.

Version **1.1** updates the repository with a PyTorch/Kaggle-style reproducible notebook and exported benchmark artifacts while keeping the original SRECG output structure centered on `SRECG.ipynb` and `comparison/`.

## What changed in 1.1

- Rewrites the end-to-end experiment notebook as a **PyTorch** workflow: no TensorFlow/Keras dependency is required for the 1.1 notebook.
- Adds Kaggle/VM path discovery for `CPSC2018Dataset`.
- Uses `np.memmap` cache handling to reduce RAM pressure during repeated ECG loading.
- Keeps 10-fold evaluation logic and exports fold indices through `FoldIndicesList.npy`.
- Adds generated result artifacts:
  - `comparison/*.npy` for benchmark, SRECG-loss, MSE, and traditional interpolation comparisons.
  - `tables/*.csv` for statistical summaries and per-lead/per-class details.
  - `figures/*.png` for benchmark, SRECG loss, and traditional interpolation visualizations.
- Adds runtime-focused `requirements.txt`; the original full environment freeze generated by the notebook is preserved as `requirements.full.freeze.txt`.

## Dataset expectation

The notebook expects the CPSC2018 dataset in the same structure used by the original experiment:

```text
CPSC2018Dataset/
├── REFERENCE.csv
├── TrainingSet1/
├── TrainingSet2/
└── TrainingSet3/
```

The notebook automatically searches common local and Kaggle paths, including `./CPSC2018Dataset` and `/kaggle/input/...`.

## Running the notebook

Install the minimal runtime packages:

```bash
python -m pip install -r requirements.txt
```

Then run `SRECG.ipynb` in Jupyter/Kaggle. For a quick smoke test, edit the notebook variable:

```python
FAST_DEV_RUN = True
```

For full reproduction, keep:

```python
FAST_DEV_RUN = False
```

## Important runtime switches

The notebook exposes these variables near the top:

| Variable | Default | Purpose |
|---|---:|---|
| `FAST_DEV_RUN` | `False` | Use `True` only for a small workflow check. |
| `REUSE_EXISTING_CHECKPOINTS` | `True` | Reuse trained checkpoints where available. |
| `REBUILD_DATA_CACHE` | `False` | Rebuild memmap cache when needed. |
| `WRITE_REQUIREMENTS` | `True` | Export a full `pip freeze` snapshot from the active environment. |
| `SRECG_BATCH_SIZE` | `64` | Optional environment override for batch size. |
| `SRECG_EPOCHS` | `100` | Optional environment override for training epochs. |
| `SRECG_DETERMINISTIC` | `0` | Set to `1` for stricter deterministic behavior at the cost of speed. |
